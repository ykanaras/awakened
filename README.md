# Awakened

Website for **Awakened**, a meditation, Buddhist-inspired wisdom, and conscious-living platform by Dimitri Kanaras.

## Current build
- Responsive landing page
- Meditation, mindful living, and Buddhist wisdom sections
- Dimitri introduction
- Membership preview and early-interest CTA
- Mobile navigation

## Roadmap
The current site is the public foundation. Planned phases include a real email signup, member authentication, subscription billing, protected meditation/audio content, a content library, and member profiles.

## Development
This first version is intentionally dependency-free: HTML, CSS, and JavaScript. Open `index.html` locally to preview it.

Domain: awakened.org
